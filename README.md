# Open-source versus cloud PAM for SME budgets

Comparative evaluation of privileged access management options for small and medium enterprises: open-source stacks versus cloud/Entra-oriented approaches, scored for cost, operability, and Essential Eight admin-restriction fit.

## Research questions

1. Which PAM capabilities matter most for an SME IT team?
2. How do open-source and cloud options compare on cost and operability?
3. What decision guide should an MSP give a budget-constrained client?

## Contents

- `01_Framework/` — requirements and criteria
- `02_Evaluation/` — workbook, cost/operability analysis, decision guide
- `Final_Submission/` — report, slides, appendices

## Limits

Laboratory / desktop evaluation artefacts. Not a vendor bake-off with production credentials. Free-tier Entra constraints are called out where relevant.
